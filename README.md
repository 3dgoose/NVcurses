# nvcare

View your NVIDIA GPU information on Linux and right from your terminal.

## Fetch

* [x] Power consumption
* [x] Model
* [x] RAM
* [x] Architecture
* [x] CUDA version
* [ ] OpenGL version
* [x] Drivers version
* [x] Fan
* [x] Temperature
* [ ] Throttle reason
* [ ] More PCIe info
* [ ] GPU Usage
* [ ] Process usage

## Install

Install it from the AUR :
```bash
yay -S nvcare
```

Compile it yourself : 
```bash
make
```


## Why

Because most GPU fetches on Linux suck. Also, I wanted to try NVML. Cool!
